# Tracker

*One row per posting that appeared in a digest or got a packet. The loop reads this before every run so nothing is surfaced twice; you update the status when you apply, hear back, or withdraw. Postings that failed a gate are not here; they go to `rejected.md` as one line each.*

Status values: `digest` · `flagged` · `close-but` · `packet built` · `skipped` · `applied YYYY-MM-DD` · `interview` · `rejected` · `withdrawn` · `dead`
