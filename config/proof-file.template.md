# Proof file — [your name]

*The only source of facts for every CV and cover letter the loop builds. If a claim is not in this file or in `cv-master.md`, it does not go into a packet. Date each entry so the loop knows you confirmed it. Rules about what to mention and when you can start live in `search-criteria.md` section 7, not here.*

How to fill this in: talk through your proudest results out loud, with the real numbers, and write them down as you said them. Then decide for each number how loud it may be used.

**"OK to use as" vocabulary:** `CV + letter` (use anywhere) · `CV only` (fine as a fact on the CV, too loud in prose) · `letter, softened as "..."` (give the softer phrasing) · `interview only` (true, but you want to explain it in person) · `not yet` (you still need to check it).
